# Profile Presets

A [Millennium](https://github.com/SteamClientHomebrew/Millennium) plugin for Steam that lets you save your full profile setup as a preset and switch between them with one click.

## Features

- Save your current profile as a named preset
- Restore any preset in one click — avatar, avatar frame, background, mini profile, theme, game profile, featured badge, and showcases (including Game Collector order)
- Update or delete saved presets anytime

> [!CAUTION]
> Don't switch presets rapidly one after another. Steam rate-limits profile edits (especially avatar uploads), and spamming applies **will get you temporarily blocked for an unknown amount of time**. Use it with care.

## Installation

1. Make sure [Millennium](https://github.com/SteamClientHomebrew/Millennium) is installed.
2. Download the latest version from the button below.
3. Extract the folder into your Millennium `plugins` directory.
4. Enable **Profile Presets** in Millennium settings.
5. Open your Steam profile → **Edit Profile** → **Profile Presets**.

[![Releases](https://img.shields.io/badge/Download-Releases-brightgreen?style=for-the-badge)](https://github.com/HEXfares/profile-presets/releases)

## Usage

- **Save:** go to the Profile Presets tab, type a name, and click *Save Preset*.
- **Apply:** click a saved preset card and confirm.
- **Update / Delete:** use the buttons on each preset card.
